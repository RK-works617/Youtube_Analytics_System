# Youtube_Analytics_System

YouTubeから動画に関する情報を取得し、分析を行うシステム。

## 機能

・YouTube Data API v3を利用して動画情報（タイトル、チャンネル名、投稿日、再生回数、動画ID）を取得。

## 使用技術

・Google AppScript(GAS)
・Google Sheets
・YouTube Data API v3



## 作成目的

GAS学習用に作った個人開発作品です。

## 学習ポイント

このシステムを作成する中で、特に以下の点を学習しました。

### YouTube Data APIの取得

今回初めてAPI連携に挑戦し、YouTube Data API v3を利用したデータ取得を実装しました。

### JSONデータからの必要情報の抽出・取得

スプレッドシートへの転記に当たって、必要となるデータを抽出するためにJSONデータの構造について理解し実際に必要なデータを取得することができました。

## 更新履歴

ver1.0　指定した動画の情報抽出、スプレッドシートへの転記。

今後はキーワード検索でヒットした動画の情報を一括取得してスプレッドシートへ転記、日次や月次で再生回数の伸びなどを分析するシステムに発展させていく予定です。
