# Youtube_Analytics_System

YouTube Data API v3を利用して動画情報を収集し、再生回数の推移や増加数の分析を行う、GAS製データ分析システム。

## 機能

・YouTube Data API v3を利用して動画情報（タイトル、チャンネル名、投稿日、再生回数、動画ID）を取得。スプレッドシートへ転記。\
・キーワード検索を実行し、検索結果から５０件の動画情報（タイトル、チャンネル名、投稿日、動画ID）を取得。スプレッドシートに転記。\
・動画IDから再生回数情報を取得。スプレッドシートへ転記。\
・日次で再生回数情報を取得し、前回再生回数との差分を計算し、データ蓄積用シートに゙差分データを蓄積。再生回数増加Top10をハイライト表示。\
・週次でバックアップを作成。合わせて各動画の週間再生回数を算出。\
・過去1週間にアップされた動画の検索結果と再生数、1日あたり再生数を取得。

## 使用技術

・Google AppScript(GAS)
・Google Sheets
・YouTube Data API v3



## 作成目的

GASとYouTube Data APIを利用したAPI連携による情報取得・分析を学習することを目的に作成した個人開発作品です。

## 学習ポイント

このシステムを作成する中で、特に以下の点を学習しました。

### YouTube Data APIの取得

今回初めてAPI連携に挑戦し、YouTube Data API v3を利用したデータ取得を実装しました。

### JSONデータからの必要情報の抽出・取得

スプレッドシートへの転記に当たって、必要となるデータを抽出するためにJSONデータの構造について理解し実際に必要なデータを取得することができました。

### 予期せぬバグへの対応

getActiveSheetでシートを指定していたために本来予定していたシートと別シートにデータが書き込まれる、といった不具合が発生していたため、シート名はgetSheetByNameを使って対象シートを明示的に指定。動画削除などでAPIがからデータを返した場合も処理を継続できるよう、エラーハンドリングを実装しました。

### バックアップの作成

データ消失・破損に備えるため週次で元データとは別のスプレッドシートにinsertSheetを使ってバックアップシートを作成、元データの内容を転記することによりデータの保護を図りました。合わせて週間再生回数のデータも保存することとしました。
